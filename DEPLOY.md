# Deploy to GitHub Pages

This is a dependency-free static site.

1. Copy the contents of this folder into your documentation repository.
2. Push to GitHub.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select your branch and either `/(root)` or `/docs`.
6. Save.

No npm, Node.js, Jekyll, or build command is required.

The site uses hash routes such as `#/architecture` so it works on GitHub Pages without server-side rewrite rules.
